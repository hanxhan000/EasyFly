# EasyFly 游戏素材说明文档

## 1. 素材总览

### 1.1 素材清单
| 类型 | 数量 | 格式 | 用途 |
|------|------|------|------|
| 飞机图片 | 1 | PNG/SVG | 玩家角色 |
| 崖壁图片 | 2 | PNG/SVG | 上下崖壁 |
| 背景图片 | 1-2 | PNG/SVG | 游戏背景 |
| UI图标 | 5-8 | PNG/SVG | 按钮、图标 |
| 音效 | 4-6 | MP3/OGG | 游戏音效 |
| 背景音乐 | 1 | MP3/OGG | 背景音乐 |

### 1.2 设计风格
- **整体风格**: 简约、扁平化、现代
- **色彩方案**: 清新、明快
- **分辨率**: 支持高清屏幕(2x, 3x)

## 2. 图片素材规格

### 2.1 飞机(Player)

#### 设计要求
- **风格**: 简约、卡通化的飞机侧视图
- **尺寸**: 80x60像素 (@1x)
- **格式**: PNG (带透明通道)
- **颜色**: 主色建议使用蓝色或橙色
- **细节**: 
  - 简化的机身
  - 简化的机翼
  - 可选的窗户装饰
  - 轻微的3D感觉(阴影)

#### 文件命名
```
player.png          (1x - 80x60px)
player@2x.png       (2x - 160x120px)
player@3x.png       (3x - 240x180px)
```

#### 参考设计描述
```
一架向右飞行的卡通飞机，采用简约扁平化设计风格。
- 机身: 流线型，蓝色渐变(#4A90E2 到 #357ABD)
- 机翼: 白色或浅蓝色，简洁的三角形
- 机头: 圆润，带有小窗户装饰
- 机尾: 小型垂直尾翼，与机身同色
- 细节: 添加轻微的高光和阴影增加立体感
- 背景: 完全透明
```

### 2.2 崖壁(Wall)

#### 上崖壁设计
- **风格**: 像素风或简约几何图形
- **尺寸**: 100x600像素 (@1x)
- **格式**: PNG (带透明通道)
- **颜色**: 灰色系或岩石纹理
- **细节**:
  - 底部边缘应该有锯齿状或不规则形状
  - 可以添加简单的纹理(裂纹、斑点)
  - 深浅不一的灰色增加层次感

#### 下崖壁设计
- 与上崖壁设计相似，但上下翻转
- 顶部边缘不规则

#### 文件命名
```
wall-top.png        (上崖壁 1x - 100x600px)
wall-top@2x.png     (2x - 200x1200px)
wall-bottom.png     (下崖壁 1x - 100x600px)
wall-bottom@2x.png  (2x - 200x1200px)
```

#### 参考设计描述
```
简约风格的岩石崖壁，垂直矩形设计。
- 主色: 深灰色(#5A5A5A)
- 质感: 添加简单的噪点纹理模拟岩石质感
- 边缘: 底部(上崖壁)/顶部(下崖壁)有不规则的锯齿状边缘
- 细节: 随机分布的深色裂纹线条(#3A3A3A)
- 渐变: 从中心向边缘轻微变暗
- 背景: 透明
```

### 2.3 背景(Background)

#### 天空背景
- **尺寸**: 1920x1080像素
- **格式**: PNG/JPEG
- **设计**: 
  - 简单的渐变天空
  - 可选的云朵装饰
  - 颜色: 蓝色到淡蓝色渐变

#### 文件命名
```
background-sky.png
background-clouds.png (可选的云层)
```

#### 参考设计描述
```
清新的天空背景，采用垂直渐变。
- 顶部: 深蓝色(#87CEEB)
- 底部: 浅蓝色/白色(#E0F6FF)
- 云朵: 白色简约几何形状，随机分布
- 风格: 扁平化，无过多细节
```

### 2.4 UI图标

#### 所需图标
1. **开始游戏按钮** (play-button.svg)
   - 播放三角形图标
   - 尺寸: 64x64px
   - 颜色: 白色或绿色

2. **排行榜图标** (leaderboard-icon.svg)
   - 奖杯或排行榜列表图标
   - 尺寸: 48x48px
   - 颜色: 金色

3. **设置图标** (settings-icon.svg)
   - 齿轮图标
   - 尺寸: 48x48px
   - 颜色: 深灰色

4. **暂停图标** (pause-icon.svg)
   - 两个竖条
   - 尺寸: 32x32px
   - 颜色: 白色

5. **音效图标** (sound-on.svg, sound-off.svg)
   - 扬声器图标
   - 尺寸: 32x32px
   - 颜色: 白色

6. **返回图标** (back-icon.svg)
   - 左箭头
   - 尺寸: 32x32px
   - 颜色: 白色

#### 文件命名规范
```
icons/
├── play-button.svg
├── leaderboard-icon.svg
├── settings-icon.svg
├── pause-icon.svg
├── sound-on.svg
├── sound-off.svg
└── back-icon.svg
```

### 2.5 Logo和标题

#### 游戏Logo
- **文本**: "EasyFly"
- **字体**: 现代、圆润的无衬线字体
- **尺寸**: 400x120px
- **格式**: SVG或PNG
- **效果**: 可添加轻微阴影或渐变

#### 参考设计描述
```
"EasyFly" 文字Logo设计
- 字体: 圆润现代字体(如Poppins, Quicksand)
- 颜色: 渐变蓝色(#4A90E2 到 #357ABD)
- 效果: 
  - 底部添加轻微阴影
  - 字母间距适中
  - 可在'Fly'部分添加小飞机装饰
- 背景: 透明
```

## 3. 音效素材

### 3.1 游戏音效

| 音效名称 | 触发时机 | 时长 | 描述 |
|---------|---------|------|------|
| button-click | 点击按钮 | 0.1s | 清脆的点击音 |
| pass-gap | 通过缺口 | 0.2s | 轻快的提示音 |
| collision | 碰撞崖壁 | 0.5s | 撞击音效 |
| game-over | 游戏结束 | 1.0s | 失败音效 |
| score-up | 分数增加 | 0.3s | 上升音调 |

### 3.2 背景音乐

| 音乐名称 | 用途 | 时长 | 风格 |
|---------|------|------|------|
| menu-bgm | 主菜单 | 循环 | 轻松、明快 |
| game-bgm | 游戏中 | 循环 | 节奏感、轻快 |

### 3.3 音频格式
- **主格式**: MP3 (兼容性好)
- **备用格式**: OGG (更小体积)
- **比特率**: 128kbps (音效) / 192kbps (音乐)
- **采样率**: 44.1kHz

### 3.4 文件命名
```
sounds/
├── sfx/
│   ├── button-click.mp3
│   ├── pass-gap.mp3
│   ├── collision.mp3
│   ├── game-over.mp3
│   └── score-up.mp3
└── music/
    ├── menu-bgm.mp3
    └── game-bgm.mp3
```

## 4. 素材生成方案

### 4.1 AI生成工具推荐

#### 图片生成
1. **DALL-E 3** (推荐)
   - 适合生成简约风格游戏素材
   - 提示词要详细描述风格和细节

2. **Midjourney**
   - 适合概念设计
   - 需要后期处理去背景

3. **Stable Diffusion**
   - 免费开源
   - 需要调整参数

#### 矢量图标
1. **Figma + AI插件**
2. **手动绘制SVG**
3. **在线图标库**: Heroicons, Feather Icons

#### 音效生成
1. **Freesound.org** (免费音效库)
2. **SFXR** (8-bit音效生成器)
3. **Bfxr** (游戏音效生成)
4. **Uppbeat / Epidemic Sound** (背景音乐)

## 5. 素材优化

### 5.1 图片优化
```bash
# 使用TinyPNG压缩
# 转换为WebP格式
npx @squoosh/cli --webp auto *.png

# 生成多倍率图片
convert player.png -resize 200% player@2x.png
convert player.png -resize 300% player@3x.png
```

### 5.2 音频优化
```bash
# 使用FFmpeg转换和压缩
ffmpeg -i input.wav -b:a 128k output.mp3
ffmpeg -i input.wav -c:a libvorbis -q:a 4 output.ogg
```

### 5.3 代码中的资源加载
```javascript
// Phaser预加载示例
class PreloadScene extends Phaser.Scene {
  preload() {
    // 图片
    this.load.image('player', 'assets/images/player.png');
    this.load.image('wall-top', 'assets/images/wall-top.png');
    this.load.image('wall-bottom', 'assets/images/wall-bottom.png');
    this.load.image('background', 'assets/images/background-sky.png');
    
    // 音效
    this.load.audio('click', 'assets/sounds/sfx/button-click.mp3');
    this.load.audio('pass', 'assets/sounds/sfx/pass-gap.mp3');
    this.load.audio('collision', 'assets/sounds/sfx/collision.mp3');
    this.load.audio('bgm', 'assets/sounds/music/game-bgm.mp3');
  }
}
```

## 8. 生成素材的行动计划

### 8.1 优先级
1. **高优先级** (MVP必需):
   - 飞机图片
   - 上下崖壁图片
   - 基础背景
   - 基础UI图标

2. **中优先级** (增强体验):
   - 基础音效
   - Logo设计

3. **低优先级** (锦上添花):
   - 背景音乐
   - 粒子效果
   - 动画帧

### 8.2 快速生成步骤
1. 使用AI生成工具(DALL-E/Midjourney)
2. 根据提示词生成基础素材
3. 使用在线工具去背景(remove.bg)
4. 调整尺寸和优化
5. 导出多倍率版本
6. 整理到项目目录

## 9. 临时素材方案

在正式素材生成前，可以使用代码绘制简单图形:

```javascript
// 临时使用Phaser绘制简单飞机
class Player extends Phaser.GameObjects.Graphics {
  constructor(scene, x, y) {
    super(scene);
    
    // 绘制简单三角形作为飞机
    this.fillStyle(0x4A90E2);
    this.fillTriangle(0, -20, 0, 20, 60, 0);
    this.setPosition(x, y);
    
    scene.add.existing(this);
  }
}

// 临时绘制崖壁
class Wall extends Phaser.GameObjects.Rectangle {
  constructor(scene, x, y, height) {
    super(scene, x, y, 100, height, 0x5A5A5A);
    scene.add.existing(this);
  }
}
```

这样可以先开发游戏逻辑，后续替换为正式素材。
