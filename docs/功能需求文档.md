# EasyFly 功能需求文档

## 1. 产品概述

### 1.1 产品定位
EasyFly是一款面向全年龄段用户的休闲H5飞行躲避游戏，以简约风格、易上手、高挑战性为特色。

### 1.2 目标用户
- 休闲游戏玩家
- 移动端用户
- 碎片化时间娱乐需求者

### 1.3 核心玩法
玩家控制飞机上下移动，躲避从右向左移动的崖壁缺口，存活时间越长分数越高。

## 2. 功能模块详细设计

### 2.1 主菜单界面

#### 2.1.1 界面元素
- **游戏Logo**: EasyFly标题
- **开始游戏按钮**: 进入游戏场景
- **排行榜按钮**: 查看Top10排行榜
- **设置按钮**: 音效、音乐开关
- **帮助按钮**: 游戏说明

#### 2.1.2 交互设计
- 按钮悬停效果(PC端)
- 按钮点击反馈动画
- 背景粒子效果(可选)

### 2.2 游戏主场景

#### 2.2.1 游戏元素

**飞机**
- 位置: 屏幕左侧固定X坐标
- 尺寸: 约60x40像素
- 行为: 
  - 只能上下移动
  - 跟随鼠标/触摸点Y坐标
  - 平滑移动，有惯性效果
- 视觉: 简约飞机图形，可能有轻微旋转动画

**崖壁系统**
- 组成: 上下两块崖壁，中间是可通过的缺口
- 生成规则:
  - 从屏幕右侧生成
  - 匀速向左移动
  - 缺口高度随机(保证可通过)
  - 缺口位置随机(上、中、下)
  - 生成间隔固定
- 难度递增:
  - 随着分数增加，移动速度加快
  - 缺口高度逐渐减小
  - 生成频率增加

**背景**
- 简约云层或山脉轮廓
- 缓慢移动制造视差效果
- 渐变色天空背景

#### 2.2.2 游戏机制

**移动控制**
- **PC端**: 鼠标按住拖动
  - 鼠标点击屏幕任意位置
  - 按住拖动，飞机跟随Y坐标
  - 松开鼠标，飞机停留当前位置
  
- **移动端**: 触摸拖动
  - 拇指触摸屏幕
  - 拖动，飞机跟随触摸点Y坐标
  - 支持单点触控即可

**碰撞检测**
- 飞机与上崖壁碰撞 → 游戏结束
- 飞机与下崖壁碰撞 → 游戏结束
- 使用精确的边界框碰撞检测

**计分系统**
- 基础分: 每成功通过一个缺口 +10分
- 时间分: 每秒 +1分
- 连续通过奖励: 连续通过5个 +20分
- 完美通过: 从缺口正中通过 +5分

**难度曲线**
| 分数区间 | 崖壁速度 | 缺口高度 | 生成间隔 |
|---------|---------|---------|---------|
| 0-50 | 200px/s | 200px | 2.5s |
| 51-100 | 250px/s | 180px | 2.2s |
| 101-200 | 300px/s | 160px | 2.0s |
| 201-300 | 350px/s | 150px | 1.8s |
| 301+ | 400px/s | 140px | 1.5s |

#### 2.2.3 UI显示
- **当前分数**: 屏幕顶部居中，大字体
- **最高分**: 分数下方小字体
- **暂停按钮**: 右上角
- **FPS显示**: 左上角(调试用，可关闭)

### 2.3 游戏结束界面

#### 2.3.1 结算信息
- 游戏结束提示: "Game Over"
- 本局分数: 大号字体高亮显示
- 最高分: 显示历史最高分
- 击败百分比: "你击败了X%的玩家"

#### 2.3.2 排名提交
- 分数达到Top10触发
- 输入框: 用户昵称(最多10字符)
- 提交按钮: 上传到云端排行榜
- 表单验证:
  - 昵称不能为空
  - 过滤敏感词
  - 防止特殊字符注入

#### 2.3.3 操作按钮
- **再来一次**: 重新开始游戏
- **查看排行榜**: 跳转排行榜页面
- **返回主菜单**: 回到主界面

### 2.4 排行榜系统

#### 2.4.1 显示内容
- 标题: "全球Top10"
- 排行列表:
  ```
  排名 | 玩家昵称 | 分数 | 时间
  --------------------------------
   1   | Player1  | 9999 | 2天前
   2   | Player2  | 8888 | 1天前
   ...
  ```

#### 2.4.2 数据管理
- 实时从云端获取
- 自动刷新(每30秒)
- 缓存机制避免频繁请求
- 显示玩家当前排名(如果在榜)

#### 2.4.3 数据结构
```json
{
  "rank": 1,
  "playerName": "Player1",
  "score": 9999,
  "timestamp": "2025-10-15T10:30:00Z",
  "playerId": "uuid"
}
```

### 2.5 设置界面

#### 2.5.1 音效设置
- 背景音乐开关
- 音效开关
- 音量调节(0-100%)

#### 2.5.2 游戏设置
- 难度选择: 简单/普通/困难
- 粒子效果开关
- 显示FPS开关

#### 2.5.3 本地存储
使用localStorage保存:
- 最高分
- 音效设置
- 游戏偏好

## 3. 用户体验设计

### 3.1 响应式设计
- **手机竖屏**: 375x667 (iPhone SE)
- **手机横屏**: 667x375 
- **平板**: 768x1024 (iPad)
- **PC**: 1920x1080+

### 3.2 加载体验
- 启动页: EasyFly Logo + 加载进度条
- 预加载所有资源
- 加载完成淡入游戏

### 3.3 动画效果
- 场景切换: 淡入淡出(300ms)
- 按钮点击: 缩放效果(0.95x)
- 分数增加: 数字跳动动画
- 游戏结束: 屏幕震动效果

### 3.4 反馈机制
- 碰撞时: 震动(移动端) + 闪烁效果
- 得分时: 音效 + 粒子效果
- 通过缺口: 短促音效

## 4. 技术需求

### 4.1 性能指标
- 首屏加载时间: < 2秒
- 游戏帧率: 稳定60fps
- 触摸响应延迟: < 16ms
- API响应时间: < 500ms

### 4.2 兼容性
- **浏览器**:
  - Chrome 90+
  - Safari 14+
  - Firefox 88+
  - Edge 90+
- **操作系统**:
  - iOS 13+
  - Android 8+
  - Windows 10+
  - macOS 10.15+

### 4.3 网络要求
- 支持离线游戏(本地模式)
- 联网时同步排行榜
- 断线重连机制
- 数据压缩传输

## 5. API接口定义

### 5.1 获取排行榜
```
GET /api/leaderboard
Response:
{
  "success": true,
  "data": [
    {
      "rank": 1,
      "playerName": "Player1",
      "score": 9999,
      "timestamp": "2025-10-15T10:30:00Z"
    }
  ]
}
```

### 5.2 提交分数
```
POST /api/leaderboard
Body:
{
  "playerName": "NewPlayer",
  "score": 1234
}
Response:
{
  "success": true,
  "rank": 8,
  "message": "恭喜进入Top10!"
}
```

### 5.3 获取玩家排名
```
GET /api/rank?score=1234
Response:
{
  "success": true,
  "rank": 156,
  "percentile": 75.5
}
```
