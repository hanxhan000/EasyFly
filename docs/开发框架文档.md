# EasyFly 开发框架文档

## 1. 技术选型

### 1.1 前端技术栈
| 技术 | 版本 | 用途 |
|------|------|------|
| React | 18.x | UI框架 |
| Vite | 5.x | 构建工具 |
| Phaser 3 | 3.70+ | 游戏引擎 |
| TailwindCSS | 3.x | CSS框架 |
| Axios | 1.x | HTTP客户端 |

### 1.2 后端技术栈
| 技术 | 版本 | 用途 |
|------|------|------|
| Node.js | 18.x+ | 运行环境 |
| Express | 4.x | Web框架 |
| MongoDB | 6.x | 数据库 |
| Mongoose | 8.x | ODM框架 |
| CORS | 2.x | 跨域处理 |

### 1.3 为什么选择Phaser 3?
- ✅ 专为HTML5游戏设计,性能优异
- ✅ 完美支持移动端触摸事件
- ✅ 内置物理引擎,碰撞检测方便
- ✅ 丰富的API和活跃的社区
- ✅ 轻量级,加载快速

## 2. 项目架构

### 2.1 前端架构
```
前端应用
├── React应用层 (UI组件、路由、状态管理)
├── Phaser游戏层 (游戏逻辑、场景管理)
└── API服务层 (数据请求、排行榜同步)
```

### 2.2 后端架构
```
后端服务
├── RESTful API (Express路由)
├── 业务逻辑层 (Controller)
├── 数据访问层 (Model)
└── 数据库 (MongoDB)
```

## 3. 开发环境配置

### 3.1 必备工具
- Node.js (v18+)
- npm/yarn/pnpm
- Git
- VS Code (推荐)
- MongoDB (本地开发) 或 MongoDB Atlas (云端)

### 3.2 VS Code推荐插件
- ES7+ React/Redux/React-Native snippets
- Tailwind CSS IntelliSense
- Prettier - Code formatter
- ESLint

### 3.3 初始化项目命令
```bash
# 创建Vite + React项目
npm create vite@latest easyfly -- --template react

# 进入项目目录
cd easyfly

# 安装依赖
npm install

# 安装游戏引擎
npm install phaser

# 安装UI相关
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p

# 安装工具库
npm install axios zustand react-router-dom

# 安装开发工具
npm install -D @types/node
```

## 4. 开发规范

### 4.1 代码规范
- 使用ESLint + Prettier进行代码格式化
- 遵循Airbnb JavaScript规范
- 组件命名采用PascalCase
- 函数和变量命名采用camelCase
- 常量命名采用UPPER_SNAKE_CASE

### 4.2 Git提交规范
```
feat: 新功能
fix: 修复bug
docs: 文档更新
style: 代码格式调整
refactor: 重构
test: 测试相关
chore: 构建/工具链相关
```

### 4.3 目录结构规范
- `components/` - React UI组件
- `scenes/` - Phaser游戏场景
- `assets/` - 静态资源
- `api/` - API接口封装
- `utils/` - 工具函数
- `hooks/` - 自定义Hooks
- `stores/` - 状态管理

## 5. 开发流程

### 5.1 本地开发
```bash
# 1. 启动后端服务 (3001端口)
cd server
npm run dev

# 2. 启动前端服务 (5173端口)
cd ..
npm run dev
```

### 5.2 调试方式
- Chrome DevTools - 常规调试
- React DevTools - React组件调试
- Phaser DevTools - 游戏场景调试
- 移动端调试 - Chrome远程调试

### 5.3 测试流程
- 单元测试: Jest + React Testing Library
- E2E测试: Playwright
- 性能测试: Lighthouse
- 兼容性测试: BrowserStack

## 7. 性能优化

### 7.1 资源优化
- 图片使用WebP格式
- 启用Gzip压缩
- 使用CDN加速
- 懒加载非关键资源

### 7.2 游戏性能优化
- 对象池管理游戏对象
- 减少不必要的渲染
- 优化碰撞检测
- 控制帧率(60fps)

### 7.3 移动端优化
- 触摸事件优化
- 屏幕适配
- 减少重绘和回流
- 电池消耗优化
